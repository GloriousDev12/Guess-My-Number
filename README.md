Guess My Number 🎯

Guess My Number is an interactive number-guessing game built with HTML, CSS, and JavaScript. The player tries to guess a randomly generated number within a given range, while the game provides feedback after each guess.

Features

🎲 Generates a random secret number.

🔢 Allows the player to enter guesses.

💬 Provides feedback for guesses that are too high or too low.

❤️ Includes a score system that decreases after incorrect guesses.

🏆 Tracks the player's high score.

🔄 Allows the player to restart the game.

⚡ Uses JavaScript DOM manipulation and event listeners for interactivity.

Technologies Used

HTML5 — Structure of the game.

CSS3 — Styling and layout.

JavaScript — Game logic, random number generation, DOM manipulation, and user interaction.

Purpose

This project was created as a JavaScript learning project to practice fundamental programming concepts while building an interactive browser game.

How to Play

Enter a number into the input field.

Click Check.

Use the feedback to determine whether your guess is too high or too low.

Keep guessing while trying to maintain the highest possible score.

Click Again to start a new game.
